# PALIMPSESTO — La costa que recuerda

**v0.1.1 · Edición en español · 25 de octubre de 2026**

RPG 2D de ciencia ficción para móviles y ordenadores. Explorá tres regiones, alterná entre MATERIA y ECO, descubrí secretos y enfrentá el misterio de una memoria que parece estar viva.

## Jugar

Accedé a [Palimpsesto en GitHub Pages](https://estebancaballeroai.github.io/palimpsesto-rpg/).

El juego está contenido en el archivo `index.html`, sin dependencias externas obligatorias y con guardado local en el navegador.

## Publicación

En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

## Versiones

- **v0.1.1:** traducción al español, mundo explorable, sistema MATERIA/ECO, combate, secretos y guardado.
- **v0.1 FR:** versión original conservada en el respaldo descargable generado en la conversación de desarrollo.
